# Coverage pass, 2026-10-18

is the only retail region. The USA preference therefore permits this image.
The player always supplies the original cartridge; no ROM is distributed.

- The 34,790-frame opening mission route reaches turn four, including ranged
  and melee combat, results, enemy turns and subsequent turns. Enhanced Japanese
  native execution with color and a 796-pixel wide view agrees with a fresh
  independent Beetle run at every labelled checkpoint across CPU, WRAM, SRAM,
  VRAM, VIP, devices, both raw eyes and audio. Fallback is zero.
- A separate fresh English/Japanese save test passes 23 checkpoints across ten
  planes. It creates, moves and reloads all three save areas, switches language,
  resaves and checks exact 64 KiB disk persistence. Truncated-input and failed-
  write checks preserve the prior files.
- The private English oracle image is reproducible from tracked editable text,
  without the historical private IPS archive. All 35 spans reproduce SHA-256
  `a143fb582956ce1f2214c0122a6cdd1f832bc82fb598c4d8a6b21102ccaab906`.
  The generator audits 137,371 generated instruction PCs and rejects code
  overlap; these 1,016 changed bytes affect text assets only.
- Later missions, endings and all translated lines have not received a complete
  playthrough. This is an opening combat and save/language validation pass.

The common build helper is in the pinned framework. Whole-function partitioning
produces 19 units with byte-identical original function bodies and dispatch in
the partition-only audit. `-FastBuild` applies lighter optimization to every
generated unit during development; production retains full optimization.

```powershell
.\tools\build.ps1 -Rom 'C:\Games\sd_gundam.vb' -Build build-release -Production
python tools/build_translation.py --framework vbrecomp --rom 'C:\Games\sd_gundam.vb' --check-reference --reference-out reference/sd_gundam_english.vb
```

The reference export refuses to overwrite the original cartridge or a different
existing file. It is private audit input and must never be packaged. See
[localization](LOCALIZATION.md), [saves](SAVES.md) and the existing committed
combat/save routes for independent-comparison commands. Automated launches use
dummy audio output with audio emulation enabled; player releases use normal audio.
